🛩️ GAVILAN Multiplayer

Simulador de Guerra Aérea Multinivel y Multijugador

👁️ Director

Control total de la simulación. Inyectar eventos, pausar, modificar condiciones. Visibilidad completa de ambos bandos.

🎖️ Estratégico

Nivel de Alto Mando. Definir ROE, objetivos estratégicos, aprobar ATOs, asignar recursos entre sectores.

📋 Operacional

Centro de Operaciones Aéreas (AOC). Crear ATOs, planificar misiones, asignar aeronaves, ordenar SCRAMBLE.

✈️ Táctico

Control de Piloto/Controlador. Control directo de aeronaves, decisiones de combate, engagement táctico.

⚙️ Administración

Gestión del sistema. Usuarios, escenarios, perfiles de IA, configuración de servidores.

Características Implementadas

  • Autenticación y autorización con JWT
  • WebSocket para comunicación en tiempo real
  • API REST completa para administración
  • Fog of War con visibilidad limitada por bando
  • IA avanzada para enemigos (dificultad escalable)
  • IA para insurgentes (tácticas asimétricas)
  • Simulador de desastres naturales
  • 3 tipos de juegos (Guerra Externa, Conflicto Interno, Desastres)
  • 4 niveles de comando jerárquicos
  • Sesiones multijugador concurrentes
